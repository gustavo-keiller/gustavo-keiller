## 🌟 Featured Project: IT Task Manager

A modern **WPF .NET 8 Enterprise Application** that demonstrates how to bring Backend Architecture (Clean Arch/DDD) to the Client Side.

* **Highlights:**
    * 🏗️ **Clean Architecture & MVVM:** Strict separation of concerns.
    * 🔄 **Custom Kanban Board:** Built from scratch with drag-and-drop logic.
    * ⚡ **In-Memory Mocking:** Custom Dependency Injection strategy for instant demo execution.
    * 🧪 **Unit Tested:** Service layer fully covered with xUnit.
